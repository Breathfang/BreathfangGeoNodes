Issues and Bug Reports
----------------------

If you hit a bug or crash, or want to request a new feature, please use the issue tracker on GitHub. That's the fastest and most reliable way to get a response.

* `Create a bug report or feature request <https://github.com/Breathfang/BreathfangGeoNodes/issues/new/choose>`_
* `Browse existing and past issues <https://github.com/Breathfang/BreathfangGeoNodes/issues>`_

.. hint::
   Before opening an issue, make sure you read the `Troubleshooting <./troubleshooting.html>`_ page and check whether your problem is already a `known issue <https://github.com/Breathfang/BreathfangGeoNodes/issues>`_. Always include your Blender version and the |packnamecode| version you are using.
