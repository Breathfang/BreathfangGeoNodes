**What is it?**

|packnamebold| is a collection of Geometry Nodes tools designed to enhance your workflow in Blender. This pack includes various node groups and deformers that can be used to create complex geometry effects with ease.

Features
--------

* `Deformer nodes <./deformers/index.html>`_ &mdash; bend, twist, stretch, taper, shear, morph and more.
* `Generator nodes <./generators/index.html>`_ &mdash; procedural geometry generation.
* Nodes are available for **Blender 4.5 LTS** and above.
