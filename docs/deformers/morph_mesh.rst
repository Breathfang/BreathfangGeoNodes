Description
-----------

Morph the mesh between two mesh states using a factor.

Usage
-----

.. image:: /_static/img/nodes/morph_mesh_example.jpg
   :target: /_static/img/nodes/morph_mesh_example.jpg

Input
-----

* **Geometry**: Mesh input.
* **Morph Target**: Targeted mesh.
* **Factor**: Morph factor.

Output
------

* **Geometry**: Mesh output
