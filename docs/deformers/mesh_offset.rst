Description
-----------

Offset the entire mesh.

Usage
-----

.. image:: /_static/img/nodes/mesh_offset_example.jpg
   :target: /_static/img/nodes/mesh_offset_example.jpg
   :width: 400px

Input
-----

* **Geometry**: Mesh input.
* **Exclusion**: Selected faces for exclusion (only on nodes).
* **Factor**: Offset factor value.

Output
------

* **Geometry**: Mesh output
* **Displacement**: Displacement map
