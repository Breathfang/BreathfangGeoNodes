Description
-----------

-----

.. image:: /_static/img/nodes/to_sphere_example.jpg
   :target: /_static/img/nodes/to_sphere_example.jpg

Input
-----

* **Geometry**: Mesh input.
* **Selection**: Selected faces (only on nodes).
* **Factor**: Offset value.

Output
------

* **Geometry**: Mesh output
